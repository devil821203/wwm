# 更新機制測試案例

- U01 來源無變更：不建立發布版。
- U02 原始快照重複：相同 hash 不重複匯入。
- U03 裝備詞條變更：差異報告含舊值、新值、版本與來源。
- U04 同一詞條來源衝突：阻止自動發布。
- U05 缺少承音明確數值：按版本模型推估且 UI 標示預估。
- U06 承音有明確數值：優先資料庫值，不乘 94%。
- U07 新資料包回歸測試失敗：不發布並保留舊版。
- U08 玩家手動修正：資料更新後保留且標記衝突待檢查。
- U09 跨國際服/中國服資料：版本未確認不得合併。
- U10 更新後重新計算 DPS：依賴預估資料的結果來源狀態同步更新。

所有案例初始狀態：NOT_RUN。
