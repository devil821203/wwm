## 四個模組

| 模組 | 外部資料來源內容 | 上傳或手動建立的實際機體 |
|---|---|---|
| 裝備 | 部位、名稱、套裝、品質基礎屬性、可用詞條、階級與條件上限、承音及滿值規則 | 實際裝備、部位、品質、等級、基礎屬性、詞條原值、套裝、培養狀態與截圖證據 |
| 人物基本資料 | 等級上限、各級基礎屬性、屬性定義、面板顯示及換算規則 | 角色名稱、流派、等級、世界等級、面板值與是否包含裝備等加成；會心率、精準率、會意率分別記錄總值與括號內實算值 |
| 心法 | 名稱、等級／突破、效果、觸發與適用條件 | 裝備中的心法、等級、狀態、實際觀察值及證據；目前記錄易水歌、無名心法、千山法、凝神章 |
| 其他 | 武學與技能、套裝效果、敵人、增益、循環及公式等影響數值的規則 | 武學與技能等級、啟用效果、敵人與循環情境、實測或其他非前三類數值 |

套裝定義及數值放在裝備模組，其實際啟動和條件與其他模組協作，避免重複計入。四模組共享來源識別、單位、可信度與資料狀態契約。

## 兩類版本與關係

1. **外部資料來源版本**：每份來源記來源 ID、URL／位置、commit／發布版本、取得時間、原始快照與 hash、授權狀態、語言／伺服器、來源聲稱的遊戲版本及適用範圍。查核時間不等於發布時間。來源未知版本明示未知；使用者指定版本作為假設，與來源證實版本分欄記錄。審核通過後由四模組的可追溯內容組成不可變資料包與 manifest，各模組可引用不同來源快照，但須明確標明適用性、衝突和缺口。
2. **實際機體版本**：每次匯入或保存建立可辨識的玩家快照，記錄角色、配置、上述四模組的實際資料、匯入／保存時間、手動輸入或截圖證據、原始精度、確認狀態及可選遊戲版本聲稱。版本識別為玩家快照修訂，與遊戲版本、來源 commit、資料包版本分開；截圖未確認的值保留候選。相同角色可有多個時間點的快照，新的快照不覆寫舊快照；刪除或取代依 UI 明確操作與備份策略處理。
3. **計算紀錄**：一次計算固定引用一份玩家快照、外部資料包、公式／模型版本及敵人與循環條件，保存解析後欄位及來源。選擇新資料包可重算，但不得回寫玩家原始值或悄悄改寫舊計算紀錄。資料不相容或版本未知時顯示原因；可依使用者明確指定的假設進行預估，缺必要資料仍阻擋可信計算。

裝備實例不強制綁遊戲版本；計算時由所選資料包解析規則。新裝備等級預設使用當前指定最高等級（目前 100），未知上限不自動補數值。裝備一律共用同一模型，來源只作稽核；紫裝獨立影響基礎屬性，滿值與承音互斥；無可靠值顯示未知並保留手動輸入。

## 資料優先序與衝突

- 實際機體：人工確認的截圖或手動值作該實例實際值，不覆寫外部資料；未確認 OCR 保留候選。外部規則與實際值衝突時顯示兩者，不擅自修改。
- 規則與理想值：同條件明確來源值優先；缺值才使用有版本、條件和依據的模型，標示「預估值」；無模型為未知，保留輸入。跨服、未知版本及不同部位／階級不可直接視為等價。
- 理想角色／裝備是獨立模擬情境，使用統一裝備模型並標示生成、預估與未驗證，不能假稱是玩家實際機體或已證明全域最優。
- 面板總值及括號內實算值分欄保存。必須記錄面板是否已含裝備、套裝及心法等加成；未知時提示並阻止會重複或漏算的合成。
- 所有衍生值傳遞來源及預估狀態；必要未知時顯示缺口，不能假裝有精確 DPS。

## 分階段實施與依賴

1. **盤點與契約**：清查四模組現有 schema、來源快照、玩家備份、IndexedDB 與計算依賴；形成欄位對照和衝突決策，確定資料包、快照、計算紀錄識別及來源狀態。先完成測試清單與管理紀錄。
2. **外部資料治理**：依來源政策完成檢查→快照→差異→審核→測試→發布，建立四模組 manifest 與回滾；不自動大量擷取未授權來源。既有來源先作候選清查，未知版本不自行升為已驗證。
3. **機體資料**：建立及編輯玩家快照，匯入截圖／JSON 或手動輸入，提供預覽、確認、備份及明確衝突處理；保護既有資料。使用者已表示無須維持舊裝備模型相容，但不主動刪除玩家資料，必要時提供可檢視的匯出與轉換方案。
4. **模組編輯與整合**：先完成既有裝備重構及四模組編輯介面，再將心法、面板語意與其他條件接到計算；缺少可信規則時保留紀錄而不宣稱可計算。
5. **計算、溯源及驗收**：以選定玩家快照和資料包建立可重現計算紀錄；明確標示預估與缺口，以鳴金·虹為首個驗證對象。S17 的既有依賴與 U01–U10 不因本方案自動完成。

## 驗收清單（未執行）

- 同一機體選不同資料包可產生可追溯的新計算紀錄；舊快照和結果不變。
- 快照匯入、編輯、備份、還原，含四模組、圖片證據及小數精度；相同 ID 衝突顯示並要求明確處理。
- 裝備手動、截圖與生成使用同一模型；紫裝、承音／滿值互斥、未知資料保留原值。
- 鳴金·虹角色 100 級、世界等級 18 分別儲存；三種比率的總值與實算值不混淆；已含加成的面板不重複累加。
- 明確值、估計、未知、來源版本衝突、跨服和 OCR 未確認的傳播均有測試；必要未知不輸出可信 DPS。
- 更新流程涵蓋 hash、差異、人工審核、失敗保留舊包、回滾及 U01–U10；執行 schema、單元、整合、建置和適用的桌面／手機 E2E，逐次記錄實際結果。

## 未決及限制

外部來源權利與國際服精確適用版本、各部位詞條上限、心法效果、鳴金·虹公式／時序與人物面板是否包含各項加成仍待核對；現階段不推定畢業裝備或 DPS 正確。方案不代表來源資料已匯入、玩家瀏覽器已有角色、或既有阻塞已解除。
