# ADR-004：S03 數值解析與本機審核
日期：2026-11-17；狀態：採用。
- 保留 S02 發行資料契約；新增獨立數值匯入 envelope，候選登錄不等於版本化證據。匯入需明確登錄 source ID、URL、原始位置與快照 hash、語言、取得/檢查/發布時間與授權審核。
- scope 精確包含版本、實體、欄位、階級、品質、培養狀態、調律階段、單位與精度；null 表示無資料/不適用，不當萬用匹配。MAX 與當前值為不同欄位 scope，不默默套用玩家當前覆寫。
- 相同條件的多個實值若不同，阻擋並列出衝突，不自動以最新或較高來源覆蓋；同值時按官方/交叉核對/社群優先選取並保留來源。衝突透過數值綁定的人工作業 selection 決策，變更後需重審。
- 玩家覆寫綁定實例與 scope，保留舊值、新值、作者、原因、日期及證據，僅影響該實例；主資料更新後覆寫仍保留並提示差異。
- 推估僅接受登錄的 SCALE 實作 ID，版本與 scope 必須完全匹配，倍率為模型提供且無預設；所有非實測結果保持 ESTIMATED，溢位/未知輸入回 UNKNOWN。其他推估實作日後登錄，不執行 JSON 程式碼。
- 匯入的 records/models 尚未審核，只有經人工 decision 與已核來源證據建立的 ReviewedDataset 可供解析。審核 digest 綁定本次 baseline、候選與差異；變動後需重建提案。
- 此為單機純函式與可序列化資料，不是使用者身分驗證或遠端權限邊界。持久化與審核 UI 留待 S04 與後續步驟；S17 完整發布門檻仍適用，不把審核通過視為可發布遊戲版本。
- 數值欄位提供四種文字標籤，必要 UNKNOWN 阻擋衍生計算；衍生結果只要含估算即標「包含預估資料」。不產生遊戲 DPS。
