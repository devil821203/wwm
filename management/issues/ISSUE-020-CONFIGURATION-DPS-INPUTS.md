# ISSUE-020：玩家配置面板與心法尚未接入期望 DPS

狀態：OPEN / BLOCKED；日期：2026-11-28。

阻塞來源：目前已保存的玩家面板 `recordedPanel` 與 `recordedInnerWays` 是手動名稱及數值，沒有對應版本屬性／心法 ID、突破等級、面板包含範圍和完整心法效果；候選 JSON 缺鳴金·虹完整技能係數及輸出事件。S08／S11 引擎需要可解析的版本化輸入；無法安全把已含裝備的面板再加裝備，亦不能省略心法後宣稱為當前配置 DPS。

依賴：資料版本重整與 S08／S11 接入、鳴金·虹來源資料核對（ISSUE-016）、心法效果／突破與面板語意。恢復條件：完成欄位映射與心法等級、來源技能／循環及條件模型，能以已確認面板或可追溯基礎合成提供必要輸入，並以遊戲實測及回歸測試驗證。可繼續：整理來源資料、編輯實際配置、顯示現有面板、使用符合引擎要求的已版本化合成測試配置。

本次配置頁展示已保存數值及明示預估的來源裸面板；存在尚未接入的手動面板或心法時禁止模擬，避免產生與配置不一致的 DPS。不能將固定 55 秒試算結果套用到任意配置。

2026-11-28：已新增 22 個玩家面板語意映射與四本心法參考映射；資料仍未轉為可直接供版本引擎使用的確認值。社群固定軸已保存 39 個項目和 35 筆技能，但缺逐動作事件時間，不能當現有戰鬥事件循環；DPS 接入仍待建立有來源的獨立參考模型或取得事件時間並完成回歸。

2026-11-28：新增依完整已含裝備面板及四種已支援心法計算的社群固定 55 秒參考軸，可輸出預估值；缺欄位阻擋、換裝需更新面板、其他屬性與套裝四件不計。原逐事件引擎、技能時序、版本化真實公式及心法突破仍未完成，維持 OPEN。
