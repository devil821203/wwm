# 06 Codex 任務清單（依序執行）

## Task 0 — 初始化
建立 pnpm monorepo、Vite React TS、Vitest、Playwright、ESLint、Prettier、CI；先寫 ADR，所有命令能在 Windows 11 執行。

## Task 1 — 資料契約與版本化
依 `schemas/paths.json` 建立路徑/武學/屬性/裝備/技能/版本 Zod schemas；加入 UNKNOWN/ESTIMATED 狀態；資料驗證器、資料覆蓋率報表與範例資料。禁止硬編碼等級上限。

## Task 2 — 資料管理與 UI
建立 9 個頁面基本導覽、Dexie 玩家庫存、角色與 Build CRUD、JSON 匯入匯出、來源/覆寫審核頁面。建立英中名稱映射與未核實標籤。

## Task 3 — 鳴金·虹數值與公式引擎
實作可追蹤來源的屬性合成、可注入公式版本、技能事件 queue、Buff、DOT、蓄力、武器切換；先用合成 fixtures 驗證，不要假裝是遊戲真實係數。建立實測資料輸入表單。

## Task 4 — 戰鬥模擬與循環
完成固定時間與優先序循環、期望值/Monte Carlo、可重現 seed、技能傷害占比、事件時間線；加入 Web Worker。

## Task 5 — 理想裝備生成器
實作四模式、詞條池合法性驗證、統一裝備庫、手動詞條編輯、生成後直接送模擬；未知資料須阻止「合法完美」宣稱。

## Task 6 — 裝備最佳化
實作約束、候選過濾、快速評分、Beam Search、局部搜尋、TopK 完整重算；以小型窮舉比對；可取消與進度回報。

## Task 7 — 所有流派的通用支援
依 `paths.json` 讓 11 流派均能建角、配裝、選等級、編輯循環、生成合法裝備（資料齊全時）、輸出可用/未知狀態。逐流派新增特殊效果 handler 與回歸案例，不能用鳴金·虹係數代替。

## Task 8 — 全等級 DPS 預測
依版本合法等級生成完整矩陣，三裝備情境×三敵人情境；有資料計算、資料缺失標 UNKNOWN、錨點校準、區間與回測報告、曲線 CSV 匯出。

## Task 9 — 發布品質
E2E、效能基準、版本更新 diff、資料授權審核、README 與使用說明。禁止未驗證數值混入正式結果。

## 每次任務交付格式
1. 修改檔案與設計決策摘要；2. 已執行的測試與結果；3. 尚缺遊戲實測資料；4. 下一任務；5. 不要跳過測試或虛構資料。

## Task 2A — 無須分類的裝備建立與截圖匯入（V1.1）
依 `docs/07-EQUIPMENT-INPUT.md` 完成手動輸入、圖片匯入、可替換 OCR adapter、欄位信心與人工審核、內部自動辨識裝備部位；不可要求玩家先選類別。OCR 不可用時必須能手動完成。

## Task 5A — 紫裝／承音／調律合法值及滿值套用（V1.1）
依 `docs/07-EQUIPMENT-INPUT.md` 實作版本化規則解析、合法值檢查、已驗證滿值帶入、統一裝備模型、差異預覽；未知規則不得自動填滿或標示合法。

## Task 2B / 5B — V1.2 裝備規則修訂（優先於舊規格）
依 `docs/08-EQUIPMENT-RULES-V1.2.md` 更新資料模型、編輯器、匯入、合法值解析、生成器、最佳化及測試。禁止 virtual/owned 分庫或分型別；紫裝基礎屬性獨立；承音按當階段既有詞條滿值×0.94 推估並依已驗證精度規則取整；調律滿值為當階理論上限。資料缺失時不得假填。
