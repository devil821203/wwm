# 05 驗收標準

## 基本
- 啟動後 11 個流派皆可被選擇；有不確定翻譯者顯示英文與待核標記；資料驅動可加第 12 條而不改 UI 程式。
- 所有國際服已配置合法等級均可查；每個流派每個等級都能返回一筆結果（可為 `UNKNOWN`，不得偽造 DPS）。
- 裝備屬性加總保留來源明細，不重複計入已含裝備的面板。
- 無來源/公式/等級資料時顯示缺失及資料品質，不崩潰。

## 鳴金·虹
- 可設定無名劍法 + 無名槍法，輸入武學與心法等級，編輯 60 秒循環。
- 使用**合成測試係數**驗證：單段、連段、蓄力、Buff 持續/到期、冷卻、切武器、DOT、敵方減傷、seed 重現。
- 在取得真實遊戲實測資料前不得把測試係數作正式 DPS 發布。
- 對固定真實樣本輸出誤差表；誤差門檻由實測基準訂定，不預先聲稱達標。

## 最佳化/生成
- 生成器不能生成不在詞條池的詞條、超出上下限、互斥組合、超出等級的裝備。
- 10 件以下小型庫存的最優解與完整枚舉一致；大型搜尋回報 `optimalityProven:false`。
- 同 seed、同資料版本、同輸入結果一致；不同 seed 的 Monte Carlo 可變動。
- 使用 Web Worker 時可顯示進度並取消，取消不破壞角色資料。

## 測試與交付
- `pnpm lint`, `pnpm typecheck`, `pnpm test`, `pnpm build` 全部通過。
- Playwright 覆蓋建立角色、編輯裝備、生成理想裝備、模擬、最佳化、匯入覆寫、等級曲線。
- 提供 README 安裝/執行/測試指令與資料版本切換說明。
