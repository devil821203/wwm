# 01 產品需求規格（PRD）

## 範圍
- Web/PWA、繁體中文優先，英文別名查找；單機離線可用，日後可加帳號同步。
- 角色：等級、境界/突破、武學等級、天賦、心法、奇術、屬性來源；一角色多 Build；角色等級選單以國際服 `level_cap` 與可用等級資料生成，**不預設固定最高等級**。
- 全流派：以 `schemas/paths.json` 為第一批 11 流派候選名冊，並保留後續版本擴充；流派組合、武學與中文譯名均可修訂。包含治療/坦克/輔助，輸出 DPS 並另提供 HPS、護盾或團隊貢獻指標，不以純 DPS 排除。
- 裝備：定義、套裝、部位、品質、階級、強化、調律、詞條池、詞條上下限、互斥、等級限制；玩家裝備實例、複製、鎖定、收藏、比較、JSON 匯入匯出。
- 理想裝備：選定等級、流派、部位、品質與目標；只從該版本合法詞條池生成；支援「理論完美」、「指定詞條」、「隨機合法」與「自有裝備微調」四模式；輸出生成規則、隨機種子、合法性報告；**不代表遊戲內獲取保證**。
- 傷害：基礎面板與裝備疊加、普通/會心/會意等命中結果、技能多段、DOT、Buff、冷卻、資源、切武器、敵方防禦與抗性、增益快照/動態結算、動作前後搖、時間軸。
- 模擬：單技能期望傷害、固定循環、優先序循環、期望值、Monte Carlo、戰鬥時間、目標類型、敵方等級、輸出技能分布/時間序列/誤差與信賴區間。
- 最佳化：玩家庫存組合、詞條再分配、理論合法完美配裝；鎖定部位、套裝要求、成本/重鑄次數、等級門檻；Top N、增益百分比、搜尋覆蓋率與最優性證明標記。
- 等級 DPS：每個版本所有合法等級，每個流派可查；顯示觀測、校準推估、外插推估或未知，並提供低/中/高三個情境、誤差區間、裝備假設、敵人與循環假設；資料不足時顯示「無法可信推估」而不是捏造數字。
- 版本：國際服版本快照、修訂記錄、資料來源、公式版本、模型版本；升版可比較並重跑基準。

## 頁面與使用流程
1. 首頁：選版本、流派、角色等級；顯示資料覆蓋率及風險。
2. 角色：基礎面板、屬性來源拆解、武學/心法/奇術。
3. 裝備庫：持有裝備、裝備詞條編輯、合法性檢查、套裝效果。
4. 理想裝備工坊：生成規則、預覽、保存到「虛擬庫存」，不可誤當持有。
5. 循環編輯：技能時間軸、優先序條件、違規提示。
6. 模擬中心：敵人與時間、運行、傷害曲線與技能占比。
7. 最佳化：目標、限制、進度、可取消、候選結果與差異。
8. 等級曲線：流派 × 等級 × 裝備情境的 DPS 曲線、可信度、資料來源；可匯出 CSV。
9. 資料管理：JSON/CSV 匯入、差異檢視、手動覆寫、版本回退。

## 非功能
- 以 Web Worker 執行模擬與搜尋；UI 不可凍結；任務可取消。
- 所有模擬輸入與輸出可序列化、可重現；使用固定 seed。
- 無資料不得顯示虛假精度；所有估計結果附方法、來源、版本與信心標籤。
- 資料與演算法分離；測試涵蓋單元、性質、整合、E2E。
- 無需帳號即可使用；避免上傳玩家隱私資訊。
